Control Your Computer
With Gestures

AirPoint is a touchless virtual mouse system that uses MediaPipe hand tracking, 1-Euro smoothing, and a finite state machine to map hand gestures to mouse actions in real-time.

System Architecture

End-to-End Pipeline

From webcam frame to OS mouse event at ~30 FPS on a laptop CPU — no GPU, no video leaves the machine. Two brains, one switch: a trained MLP reads the hand shape; a state machine turns shapes over time into actions.

📸
Webcam Feed
30 FPS frames via OpenCV, mirrored
→
🤚
MediaPipe Hands
21 3D landmarks per frame
→
📐
Normalization
63-D: wrist at origin, palm length = 1 — same hand near or far
→
🧠
Pose Classifier
MLP 63→128→64→6 poses, 0.1 ms. Rule baseline kept as live fallback (k)
→
🗳️
Vote Smoother
Majority of last 5 frames, confidence ≥ 0.75 — one bad frame never clicks
→
🎯

Learning Loop

The classifier is trained on real hands, not hand-written thresholds. Recording a new person takes 80 seconds; retraining takes two.

⏺️
Record
6 poses × 10 s per person. A capture guard rejects frames that contradict the label
→
📊
Dataset
Raw landmark CSV per person; normalized at train and inference time
→
🏋️
Train
±34° tilt + noise augmentation; accuracy reported leave-one-user-out — on hands never seen
→
🚀
Live
Model file loads into the demo; k flips rules ↔ MLP on stage
